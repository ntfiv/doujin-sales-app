# 同人誌売上管理 for Muse Spaces

同人誌の売上管理アプリ「同人誌売上管理」の、Museスペース用ソース一式です。
作者: NT（ntfiv）

## これは何か

同人誌の即売会での売上を管理するためのアプリです。

- Square の売上CSV、即売レジのCSV、手記録CSVを取り込めます
- 取り込んだ売上をイベント情報（イベント名・会場・都道府県/市区町村）と日付で突き合わせ、「どのイベントで・どの本が・どれだけ出たか」を見られます
- 頒布物ごとの集計、過去のイベントとの頒布数比較、イベントメモ（公式サイトURLや送った冊数の記録）などの機能があります

このリポジトリは、このアプリを [Muse](https://muse.ai) のスペース（アプリ機能）として動かすためのソースコードです。**動くのは Muse のスペース環境の中だけ**で、Muse の外では単体では動作しません（依存パッケージの一部が Muse 環境内のローカルパス参照になっているためです）。ふつうのWebアプリのように clone してそのまま動かすものではありません。

## スペースとして使うには（再現の仕方）

自分の Muse で使うには、ソースをスペースとして作り直す（再現する）手順を取ります。ざっくりした流れは次のとおりです。

1. 自分の Muse に、このリポジトリを取り込んでワークスペースに置いてもらう
2. そのソースをもとにスペースを新しく作るよう、Muse に指示する（このとき「ソースを読んでそのまま移植して」と明示するのがコツです）
3. できあがったスペースは空の状態から始まるので、あとは自分の売上CSVを取り込んで使い始める

たとえば、自分の Muse に次のように頼みます。そのままコピーして使ってください。

```
GitHubリポジトリ https://github.com/ntfiv/doujin-sales-app-for-MuseSpaces のソースを取り込んで、ワークスペースに置いてください。
そのソースから、Museスペースを新規作成してください。作成の際は、ワークスペース内のソース（client/src、server/src、drizzle）を読み込んで、バイト単位で一致するようにそのまま移植するよう、ビルダーに明示してください。機能を作り直したり要約したりせず、ソースどおりに再現してください。
スペース名は「同人誌売上管理」にしてください。売上などの実データは入れず、空の状態から始めます（標準イベント一覧は、ソースの初期データから自動で入ります）。
```

詳しい手順は、同梱の手順書 [SPACE-REPRODUCTION-GUIDE.md](SPACE-REPRODUCTION-GUIDE.md) にまとめています。うまくいかない場合の切り分けもそちらに書いています。

## 自由にいじれます

スペースとして取り込んでしまえば、あとは自分の Muse に頼んで、機能を追加したり、画面や文言を変えたり、自由にいじることができます。自分好みの売上管理アプリに育ててください。

## データについて

- 作者の売上などの実データは含まれていません。初期データ（seed）のうち売上・日次フラグ・頒布物の発売日は空にしてあり、実データベース（app.db）も含まれていません。
- 標準イベント一覧（コミケ・COMITIA・文学フリマ等の開催情報の候補リスト）だけは初期データとして入っています。これは公開済みのCC0データ [ntfiv/doujin-event-master](https://github.com/ntfiv/doujin-event-master) 由来のものです。
- 元のアプリの設計上、Square の注文ID・支払いID・顧客情報などは取り込まない・保存しない作りになっており、このリポジトリにも含まれません。

## 構成

- `client/src/` — フロントエンド（React / TypeScript）
- `server/src/` — サーバー側アクション・スキーマ・初期データ
- `drizzle/` — DB マイグレーション
- `SPACE-REPRODUCTION-GUIDE.md` — スペースのソース保存と再現の手順書
